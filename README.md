# بات سورپرایز نادیا

بات تلگرام پایتونی با این قابلیت‌ها:
- منوی کاربری: آهنگ رندوم، شب‌بخیر، پیام از متی، سورپرایز تصادفی
- پنل مدیریت با دستور `/admin` که فقط مدیر تعیین‌شده به آن دسترسی دارد
- ارسال پیام همگانی به کاربرانی که `/start` زده‌اند
- اضافه‌کردن فایل صوتی آهنگ و متن شب‌بخیر از داخل تلگرام
- ذخیره اطلاعات در SQLite

## 1) ساخت بات و گرفتن توکن
1. در تلگرام به `@BotFather` پیام بده.
2. دستور `/newbot` را بفرست و مراحل را انجام بده.
3. توکن را محرمانه نگه دار؛ آن را برای هیچ‌کس نفرست.

## 2) پیدا کردن شناسه عددی تلگرام خودت
از یک بات معتبر نمایش شناسه تلگرام استفاده کن یا با یک بات کوچک موقت شناسه‌ات را دریافت کن. مقدار عددی خودت را به‌عنوان `ADMIN_ID` قرار بده. به نام کاربری اکتفا نکن.

## 3) اجرا روی کامپیوتر برای آزمایش
Python 3.10 یا جدیدتر نصب کن. داخل پوشه پروژه اجرا کن:

```bash
python -m venv .venv
```

Windows:
```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:BOT_TOKEN="توکن_بات"
$env:ADMIN_ID="شناسه_عددی_خودت"
python main.py
```

Linux/macOS:
```bash
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="توکن_بات"
export ADMIN_ID="شناسه_عددی_خودت"
python main.py
```

## 4) استفاده
- `/start`: نمایش منوی کاربری و ثبت کاربر در دیتابیس
- `/admin`: پنل مدیر
- `📣 ارسال پیام همگانی`: بعد از انتخابش، پیام بعدی‌ات برای همه کاربران ثبت‌شده کپی می‌شود.
- `🎵 اضافه‌کردن آهنگ`: بعد از انتخابش، یک فایل صوتی به‌صورت Audio بفرست.
- `📝 اضافه‌کردن شب‌بخیر`: متن جدید بفرست.
- `/cancel`: لغو عملیات در حال انجام

برای آزمایش ارسال همگانی، اول بات را از یک حساب آزمایشی `/start` کن. بات فقط می‌تواند به کاربرانی پیام بدهد که خودشان بات را شروع کرده‌اند و بات را مسدود نکرده‌اند.

## 5) میزبانی 24 ساعته
روی یک هاست Python که اجرای Worker/Background Service و اتصال خروجی به اینترنت را پشتیبانی کند:
1. فایل‌های `main.py` و `requirements.txt` را بارگذاری کن.
2. دستور نصب: `pip install -r requirements.txt`
3. دستور اجرا: `python main.py`
4. متغیرهای محیطی را تنظیم کن: `BOT_TOKEN` و `ADMIN_ID`.
5. **دیسک پایدار** برای فایل `bot_data.sqlite3` فعال کن و مسیرش را با `DB_PATH` تنظیم کن. اگر فضای دیسک موقت باشد، فهرست کاربران و آهنگ‌ها با ری‌استارت ممکن است از بین برود.

اگر هاستت از متغیرهای محیطی یا دیسک پایدار پشتیبانی نمی‌کند، برای این بات مناسب نیست. پلن‌های رایگان ممکن است سرویس را بخوابانند؛ برای کارکرد واقعی 24/7 یک Worker همیشه‌فعال لازم است.

## نکات مهم
- توکن را در GitHub عمومی یا پیام گروهی قرار نده. اگر لو رفت، از BotFather توکن را عوض کن.
- پیام همگانی را فقط برای پیام‌هایی استفاده کن که کاربران انتظار دریافتشان را دارند؛ ارسال زیاد یا ناخواسته می‌تواند باعث گزارش یا محدودیت بات شود.
- فایل صوتی باید مجاز به اشتراک‌گذاری باشد. بات فایل را از روی `file_id` تلگرام ارسال می‌کند و فایل صوتی روی هاست ذخیره نمی‌شود.
